# What was done

1. Список постов рендерится динамически с использованием API endpoints.

2. Реализована страница добавления поста. При незаполнении пользователем
   обязательных полей, выводится соответствующее сообщение. Специальные символы,
   введённые в полях формы, предварительно обрабатываются, не образуют HTML-тегов
   и никак не изменяют структуру DOM-дерева.

3. Добавлена возможность просмотра страницы с постами конкретного пользователя.
   Список постов выбранного автора также рендерится динамически.

4. Полностью реализован функционал лайков. Только авторизованные пользователи
   могу поставить/отжать лайк. Если пользователь ранее где-то ставил лайк,
   то, при рендере списка постов (и конкретного пользователя и общего),
   такой лайк отобразится у авторизованных пользователей.

5. Изначальный fork существенно не изменялся. Весь новый функционал только
   дополнялся к уже существующему коду.

# additional features

1. Анимация лайка/дизлайка для лучшего UX 👍

2. Добавлена страница с анимацией загрузки при осуществлении пользователем действий,
   требующих ре-рендера списка постов, вместо простой информационной надписи
   без стилей - например: "Здесь будет страница фотографий пользователя..."

3. Часа за полтора я смог угадать как подключить npm пакет date-fns
