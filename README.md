# SkyproInstapro

📖 О приложении:
skypro-instapro – приложение, имитирующее базовый функционал для обмена фотографиями. 
Фокусируется на работе с реальным API и кастомным роутингом на клиентской стороне. 
Это полноценное SPA-приложение с авторизацией, лентой постов и возможностью взаимодействия с контентом. 
Проект демонстрирует умение разбираться в чужой логике и дорабатывать legacy-код.

🛠️ Технологии:
HTML5 
CSS3
JavaScript (ES6+)
REST/Fetch API 
NPM

🚀 Особенности: 
Защита от XSS – экранирование HTML
Валидация полей форм
Работа с существующей кодовой базой
Реализация кастомного роутинга
🔐 Неавторизованные пользователи:
✅ Просмотр общей ленты
✅ Просмотр лент конкретных пользователей
❌ Не могут добавлять посты
❌ Не могут ставить лайки
🔐 Авторизованные пользователи:
✅ Все возможности гостей
✅ Добавление новых постов
✅ Лайки в любой ленте
✅ Сохраненная сессия (Local Storage)

📁 Структура проекта:
<>
   assets/			   // Статические файлы 
		fonts		         // шрифты
      images		      // изображения
   components/ 	   // Логика рендера UI компонентов

   favicon.ico 	   # Фавикон
   helpers.js		   # Вспомогательные функции
   index.html		   # Страница приложения

   package-lock.json	# Описание дерева зависимостей

   styles.css 		   # CSS файл стилей приложения

</>
